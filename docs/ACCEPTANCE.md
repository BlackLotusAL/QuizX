## 11.1 题库、导航与进度

- [x] 题目固定按“单选题 → 判断题 → 多选题”排列，同题型内保持题库原顺序。（仓库、API 与 E2E）
- [x] 主标题显示当前题型，右侧显示全局位置；题号不等同于 JSON 下标或题目 ID。（组件与 E2E）
- [x] 桌面显示吸顶答题导航；移动端显示“题目导航 x / n”并打开复用分区的底部抽屉。（组件、E2E 与可视化巡检）
- [x] 空题型不显示；各分区显示题数与全局数字题号。（仓库与 API 测试）
- [x] 题号以边框、圆点和勾选表达当前、草稿、已提交、未作答，不显示对错。（DOM 断言与可视化巡检）
- [x] 任意作答状态都可数字跳题或使用上一题、下一题；首末题禁用且不循环。（组件与 E2E）
- [x] 移动端选题后关闭抽屉并聚焦新题标题。（E2E 与可视化巡检）
- [x] 无记录显示“开始练习”，有位置、草稿或反馈时始终显示“继续练习”，不存在“重新练习”。（组件与 E2E）
- [x] 清空记录需要确认，只影响当前题库并回到第 1 题。（组件与 E2E）
- [x] 任意数量题目提交后均不生成完成页、分数、正确率或统计。（组件与 E2E）

- [x] 草稿即时保存，判题后保存完整反馈；切题、刷新和返回题库后均可恢复。（组件与 E2E）
- [x] 旧结构一次性重置并提示“题目导航已更新，将从第 1 题开始”。（进度与组件测试）
- [x] 题库版本变化、记录损坏或题目 ID/选项不匹配时，仅清理对应失效记录。（进度、组件与 E2E）
- [x] 本地存储读取或写入失败时退化为页面内存状态，不阻断当前练习。（进度与组件测试）
- [x] 提交或切题失败时保留当前题目、选择和反馈，提供明确重试。（组件与请求拦截 E2E）

## 11.3 作答与反馈

- [x] 单选题与判断题只能选择一个选项，多选题按完整集合判定。（API 与组件测试）
- [x] 空答案不能提交；非法选项由后端拒绝。（组件与 API 400 契约测试）
- [x] 提交成功后锁定当前题，反馈展示正确选项、错选和解析。（组件与 E2E）
- [x] 反馈状态使用文字与图标，不只依赖颜色；导航不泄露答题对错。（DOM 断言与可视化巡检）

## 11.4 内容与 API

- [x] 取题接口以新的展示位置取题，返回 `QuestionSection[]`，且不返回正确答案或解析。（仓库、API 与 E2E）
- [x] 题目 ID 与判题接口保持不变，没有新增产品 API。（构建路由清单与 API 测试）
- [x] 合法 JSON 启动时载入内存；运行中保持只读；非法 JSON 阻止启动并给出文件与语法位置。（生命周期测试）
- [x] 示例题库版本已递增，版本失效流程返回第 1 题。（数据校验、组件与 E2E）
- [x] 不存在的题库、题目或位置返回 404；旧题库版本提交返回 409。（API 与 E2E）

## 11.5 范围守卫

- [x] 系统不要求账号、身份或权限，不连接数据库，也不保存服务端学习记录。
- [x] 系统不包含级别选择、考试、复习、管理、统计或完成状态。
