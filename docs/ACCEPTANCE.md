## 11.1 题库与进度

- [x] 根路由直接显示题库卡片，不存在独立首页或分类筛选。（Chrome E2E + 可视化巡检）
- [x] 卡片只显示名称、简介、题数和一个主操作。（`bank-list-page.test.tsx` + 可视化巡检）
- [x] 无进度、进行中和已完成分别显示“开始练习”“继续练习”“重新练习”。（组件测试 + Chrome E2E）
- [x] 用户中断后可在同一浏览器从正确题号继续。（Chrome E2E）
- [x] 本地进度不包含答案、对错或成绩。（`progress.test.ts`）
- [x] 完成题库后不生成分数或统计，可返回题库或重新练习。（组件测试 + Chrome E2E）

## 11.2 作答与反馈

- [x] 单选题与判断题只能选择一个选项并正确判题。（API、组件及 E2E 测试）
- [x] 多选题只有选项集合完全匹配时才判定正确。（API 测试覆盖乱序、少选和正确集合）
- [x] 空答案不能提交；非法选项由后端拒绝。（组件测试 + API 400 契约测试）
- [x] 提交成功后锁定当前题选项，不能重复作答。（组件测试 + 可视化巡检）
- [x] 回答正确时显示正确状态、正确选项和解析。（组件测试 + Chrome E2E）
- [x] 回答错误时同时标出错选与全部正确选项，并显示解析。（组件测试 + Chrome E2E）
- [x] 反馈状态使用文字和图标，不只依赖颜色。（DOM 断言 + 可视化巡检）
- [x] 提交或加载失败时保留当前上下文和选择，并可重试。（组件测试 + 请求拦截 E2E）

## 11.3 内容加载

- [x] 合法 JSON 在重启后载入内存并可用于刷题。（生命周期烟测）
- [x] 修改 JSON 但不重启时，运行中内容不发生变化。（生命周期烟测）
- [x] 任一 JSON 非法时服务拒绝启动，不发生部分载入。（加载器测试 + 生命周期烟测）
- [x] 启动错误可以定位到具体文件、字段和原因。（加载器测试 + 生命周期日志断言）
- [x] 空题库目录允许启动，前端显示真实空状态。（加载器测试 + 题库页组件测试）
- [x] 题库版本变化后，旧本地进度被清除并从第 1 题开始。（进度、组件及 E2E 测试）

## 11.4 API

- [x] `GET /api/banks` 只返回题库摘要并按标题排序。（仓库/API 测试）
- [x] 取题接口不返回或泄露正确答案与解析。（API 测试 + E2E 请求断言）
- [x] 判题接口返回 `isCorrect`、正确选项和必填解析。（API 测试）
- [x] 空答案或非法答案返回 400。（API 参数化测试 + E2E）
- [x] 不存在的题库、题目或题号返回 404。（API 测试 + E2E）
- [x] 旧题库版本提交返回 409，前端执行更新流程。（API、组件及 E2E 测试）
- [x] 除题库列表、取题和判题外不存在其他产品 API。（Next.js 构建路由清单）

## 11.5 范围守卫

- [x] UI、JSON 与 API 中均不存在级别字段或选择流程。（Schema 拒绝未知字段 + 代码巡检）
- [x] 系统不要求账号、身份或权限。（路由与依赖巡检）
- [x] 系统不连接数据库，也不保存服务端学习数据。（依赖与服务端实现巡检）
- [x] 系统不包含考试、复习、管理或统计能力。（页面、API 与构建路由清单巡检）
