# QuizX 产品需求文档

## 1. 产品定义

QuizX 是一个通用的极简刷题 Web 应用。它只解决一个问题：让用户选择适合自己的题库，逐题作答，并在每次提交后立即理解答案为什么对或错。

产品只保留以下闭环：

1. 选择题库。
2. 阅读题目并选择答案。
3. 提交答案。
4. 查看对错、正确答案和解析。
5. 在题型分区内自由切换题目，持续练习或回看解析。

任何不能直接缩短或改善这条链路的能力，均不进入 MVP。

### 1.1 目标用户

需要通过选择题进行自学、复习或知识检验的用户。QuizX 不限定行业、考试或知识领域，具体内容完全由题库 JSON 决定。

### 1.2 核心价值

- **选择简单**：用户根据题库名称、简介和题数直接选择，不需要理解额外分类体系。
- **作答专注**：页面一次只呈现一道题，不展示与当前作答无关的信息。
- **反馈及时**：每次提交后立即展示对错、正确答案与必填解析。

### 1.3 MVP 成功标准

- 用户从题库页只需一次点击即可进入第一题或继续上次进度。
- 每道题在提交成功后都能得到明确、完整的解释。
- 单选题、多选题和判断题均能被正确呈现与判定。
- 中断后可在同一浏览器继续，但服务端不保存任何个人数据。
- 产品运行不依赖数据库，只需要合法的题库 JSON 文件。

## 2. 产品边界

### 2.1 MVP 范围

- 题库卡片列表。
- 开始和继续练习题库。
- 单选题、多选题、判断题。
- 按题型分区的题号导航与上一题、下一题切换。
- 逐题作答与即时判题。
- 正确选项、错误选项和解析展示。
- 浏览器本地位置、草稿与反馈恢复。
- 服务启动时加载并校验题库 JSON。
- 三个只服务于题库列表、取题和判题的 API。

### 2.2 明确不做

- 账号、登录、用户身份、角色或权限。
- 级别、科目、语言、标签、筛选、搜索或推荐。
- 独立首页、导航中心或营销页面；根路由直接展示题库。
- 随机顺序或背诵模式。
- 错题本、收藏、笔记、跨题库作答历史、成绩或学习统计。
- 模拟考试、倒计时、排名、积分、徽章或证书。
- 题目管理后台、在线编辑、上传、导入或导出 API。
- 图片、附件、外链资源或富媒体题目。
- 数据库、缓存服务、消息队列或服务端进度。
- 多主题、复杂动效或独立原生移动端应用。
- 防作弊机制；该产品用于学习，不限制用户主动调用判题接口。

## 3. 信息架构

MVP 只有两个页面。

| 页面 | 路由 | 目的 |
|---|---|---|
| 题库页 | `/` | 浏览题库并开始或继续练习 |
| 刷题页 | `/practice/:bankId` | 逐题作答并查看即时反馈 |

刷题页桌面端提供题目级右侧导航，窄屏收纳为底部抽屉；它不是全局一级导航。页面仍保留返回题库页的入口。

## 4. 核心交互

### 4.1 题库页

题库按标题升序展示。每张卡片只包含：

- 题库名称。
- 一段简短介绍。
- 题目总数。
- 一个主操作按钮。

按钮文案由本地进度决定：

| 本地状态 | 按钮 | 点击结果 |
|---|---|---|
| 无进度 | 开始练习 | 从第 1 题进入 |
| 有记录 | 继续练习 | 从 `currentPosition` 对应题目进入并恢复选择或反馈 |

题库不设置“已完成”状态。用户可在刷题页主动清空当前题库记录，清空前必须确认。

### 4.2 刷题页布局

页面从上到下依次展示：

1. 返回题库页入口、题库名称、当前题型和 `当前题 / 总题数`。
2. 桌面右侧题目导航，或窄屏“题目导航”抽屉入口。
3. 题干和选项。
4. 主操作按钮“提交答案”。
5. 提交成功后出现的反馈区。
6. 始终可用的次级操作“上一题”和“下一题”。

页面一次只展示一道题。题目导航固定按“单选题 → 判断题 → 多选题”分区，同题型内保持题库 JSON 原顺序；不存在的题型不显示空分区。

### 4.3 选择与提交

- 单选题和判断题使用单选交互，只允许选择一个选项。
- 多选题使用复选交互，允许选择一个或多个选项。
- 未选择任何选项时，“提交答案”不可用。
- 点击提交后，在响应返回前禁用重复提交。
- 若请求失败，保留当前选择，恢复提交按钮并允许重试。
- 若提交成功，锁定选项；当前题不能再次作答。

判题规则：

- 单选题与判断题：所选唯一选项等于唯一正确选项时为正确。
- 多选题：忽略选项顺序，所选选项集合与正确选项集合完全相同时为正确；少选、多选或错选均为错误。

### 4.4 即时反馈

提交成功后，反馈必须直接出现在当前题下方，不跳转页面，也不增加人为等待或结果动画。

回答正确时：

- 显示“回答正确”。
- 标记正确选项。
- 显示题目解析。

回答错误时：

- 显示“回答错误”。
- 标记用户选错的选项。
- 标记所有正确选项。
- 显示题目解析。

选项状态不能只依赖颜色，还必须有文字或图标标识，确保状态可辨识。

### 4.5 题目导航与切换

- 题目导航按题型展示全局数字题号，区分当前题、未作答、已选择未提交和已提交；不显示对错。
- “上一题”和“下一题”始终展示，首题或末题禁用对应按钮，不循环切换。
- 用户可在未提交时直接切题；当前选择先写入本地记录，不弹出确认。
- 目标题加载成功后才更新 `currentPosition`；加载失败时保留原题、选择或反馈，并提供重试。
- 提交后的题目继续锁定，返回时完整恢复选择、对错标记和解析。
- 导航只显示“已提交 x / n”，不显示分数、正确率或完成提示。
- “清空答题记录”仅清除当前题库，确认后返回第 1 题；其他题库记录不受影响。

## 5. 本地进度

练习记录使用浏览器 `localStorage`，键名固定为 `quizx.progress`，当前结构版本为 2。

```json
{
  "schemaVersion": 2,
  "banks": {
    "javascript-basics": {
      "bankVersion": 3,
      "currentPosition": 5,
      "attempts": {
        "1": {
          "questionId": "q001",
          "selectedOptionIds": ["C"],
          "result": {
            "isCorrect": true,
            "correctOptionIds": ["C"],
            "explanationMd": "答案解析"
          }
        },
        "5": {
          "questionId": "q003",
          "selectedOptionIds": ["A", "B"]
        }
      }
    }
  }
}
```

字段含义：

| 字段 | 说明 |
|---|---|
| `schemaVersion` | 本地记录结构版本，固定为 `2` |
| `banks` | 按题库 ID 保存的记录 |
| `bankVersion` | 保存记录时的题库版本 |
| `currentPosition` | 最近成功展示的全局题号，从 1 开始 |
| `attempts` | 按全局题号保存的草稿或已提交结果 |
| `questionId` | 用于校验位置对应的题目未发生漂移 |
| `selectedOptionIds` | 当前已选选项；存在 `result` 时代表已提交答案 |
| `result` | 判题接口返回的对错、正确选项和解析；草稿不包含此字段 |

约束：

- `currentPosition` 和 `attempts` 的题号范围均为 `1..题目总数`。
- 选择变化后立即保存草稿；判题成功后保存完整反馈，判题失败仍保留草稿。
- 记录只保存在当前浏览器，不创建服务端用户状态或聚合成绩。
- 结构版本 1 的旧记录因题号顺序变化而一次性清空，并提示“题目导航已更新，将从第 1 题开始”。
- 本地存储缺失、不可用或内容损坏时，忽略旧值并从第 1 题开始，不阻断刷题。
- 题库列表返回的版本与本地版本不一致时，清除该题库进度，并提示“题库已更新，将从第 1 题开始”。
- 题库已被删除时，清除对应本地进度；直接访问其刷题路由时返回题库页并提示题库不存在。

## 6. 题库 JSON 规范

### 6.1 文件约定

- 路径：`data/question-banks/*.json`。
- 一个文件只定义一个题库。
- 文件编码为 UTF-8。
- 顶层字段固定为 `id`、`title`、`description`、`version`、`questions`，不记录其他版本信息。
- JSON 是题库内容的唯一真源，不同步到数据库。
- 题目按 `questions` 数组中的顺序呈现。
- 任何题目内容、答案或顺序发生变化时，内容维护者必须递增题库 `version`。
- 文件不位于 Web 静态资源目录，不能被浏览器直接下载。

### 6.2 完整示例

```json
{
  "id": "javascript-basics",
  "title": "JavaScript 基础",
  "description": "适合复习 JavaScript 核心语法与常见行为。",
  "version": 3,
  "questions": [
    {
      "id": "q001",
      "type": "single",
      "stemMd": "`const` 声明的变量具有什么特点？",
      "options": [
        { "id": "A", "text": "可以在同一作用域重复声明" },
        { "id": "B", "text": "声明后必须始终指向同一值" },
        { "id": "C", "text": "绑定不能被重新赋值" },
        { "id": "D", "text": "自动成为全局变量" }
      ],
      "correctOptionIds": ["C"],
      "explanationMd": "`const` 禁止重新赋值变量绑定，但对象内部的可变内容仍可修改。"
    }
  ]
}
```

### 6.3 字段定义

#### 题库

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| `id` | string | 是 | 全局唯一；只允许小写字母、数字和连字符 |
| `title` | string | 是 | 非空，用于题库卡片和刷题页标题 |
| `description` | string | 是 | 非空，帮助用户判断是否适合自己 |
| `version` | integer | 是 | 大于等于 1；内容或顺序变化时递增 |
| `questions` | array | 是 | 至少包含一道题 |

#### 题目

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| `id` | string | 是 | 在当前题库内唯一 |
| `type` | enum | 是 | `single`、`multiple` 或 `judgment` |
| `stemMd` | string | 是 | 非空；支持受限 Markdown |
| `options` | array | 是 | 选项 ID 在当前题目内唯一，文本非空 |
| `correctOptionIds` | string[] | 是 | 只能引用当前题目的选项 ID |
| `explanationMd` | string | 是 | 非空；必须解释正确答案及常见错误原因 |

题型校验：

| 题型 | 选项数量 | 正确选项数量 |
|---|---:|---:|
| `single` | 2–6 | 1 |
| `multiple` | 2–6 | 至少 2 |
| `judgment` | 固定 2 | 1 |

### 6.4 Markdown 白名单

题干与解析仅支持：

- 段落与换行。
- 粗体和斜体。
- 有序与无序列表。
- 行内代码。
- fenced code block。

不渲染原始 HTML、链接、图片、脚本、内联事件或其他外部资源。选项文本始终按纯文本渲染。

## 7. 服务启动与内容加载

启动流程：

1. 扫描 `data/question-banks/*.json`。
2. 解析全部文件。
3. 按第 6 节规则校验全部题库和题目。
4. 只有全部文件都通过校验，才一次性载入内存并开始提供服务。
5. 内容在本次进程生命周期内保持只读；修改文件不会热更新，必须重启服务。

错误策略：

- 任一文件解析或校验失败，服务拒绝启动，不允许只加载部分题库。
- 错误日志必须包含文件路径、JSON 字段位置和失败原因。
- 不存在任何 JSON 文件时允许服务启动，`GET /api/banks` 返回空数组，前端展示空题库状态。
- 多个文件使用相同题库 ID 时视为校验失败。

运行时不创建数据库连接，不写入题库文件，也不提供内容修改接口。

## 8. API 契约

所有响应使用 JSON。错误统一返回：

```json
{
  "error": {
    "code": "BANK_NOT_FOUND",
    "message": "题库不存在"
  }
}
```

### 8.1 获取题库列表

`GET /api/banks`

成功响应：`200 OK`

```json
[
  {
    "id": "javascript-basics",
    "title": "JavaScript 基础",
    "description": "适合复习 JavaScript 核心语法与常见行为。",
    "version": 3,
    "questionCount": 30
  }
]
```

规则：

- 结果按 `title` 升序排列。
- 无题库时返回 `[]`，不视为服务错误。
- 不返回题目内容或答案。

### 8.2 按位置获取题目

`GET /api/banks/:bankId/questions/:position`

成功响应：`200 OK`

```json
{
  "bank": {
    "id": "javascript-basics",
    "title": "JavaScript 基础",
    "version": 3
  },
  "position": 1,
  "total": 30,
  "sections": [
    { "type": "single", "startPosition": 1, "count": 15 },
    { "type": "judgment", "startPosition": 16, "count": 5 },
    { "type": "multiple", "startPosition": 21, "count": 10 }
  ],
  "question": {
    "id": "q001",
    "type": "single",
    "stemMd": "`const` 声明的变量具有什么特点？",
    "options": [
      { "id": "A", "text": "可以在同一作用域重复声明" },
      { "id": "B", "text": "声明后必须始终指向同一值" },
      { "id": "C", "text": "绑定不能被重新赋值" },
      { "id": "D", "text": "自动成为全局变量" }
    ]
  }
}
```

规则：

- `position` 为固定题型排序后的全局位置，是从 1 开始的整数。
- 服务端按 `single`、`judgment`、`multiple` 稳定分组，同题型内保持 JSON 原顺序。
- `sections` 只返回非空题型的类型、起始位置与数量，不包含题目内容或答案。
- 响应不得包含 `correctOptionIds`、`explanationMd` 或任何可推导正确答案的字段。
- 题库不存在时返回 `404 BANK_NOT_FOUND`。
- 题号不是正整数或超出范围时返回 `404 POSITION_NOT_FOUND`。

### 8.3 提交答案

`POST /api/banks/:bankId/questions/:questionId/answer`

请求：

```json
{
  "bankVersion": 3,
  "selectedOptionIds": ["B"]
}
```

成功响应：`200 OK`

```json
{
  "isCorrect": false,
  "correctOptionIds": ["C"],
  "explanationMd": "`const` 禁止重新赋值变量绑定，但对象内部的可变内容仍可修改。"
}
```

规则：

- 接口只判题并返回反馈，不创建会话或记录。
- `selectedOptionIds` 不能为空、不能重复，也不能包含不存在的选项。
- 单选题和判断题提交多个选项时返回 `400 INVALID_ANSWER`。
- 多选题提交一个合法选项属于有效作答，按答案集合判定，不因少选而返回 `400`。
- 题库不存在时返回 `404 BANK_NOT_FOUND`。
- 题目不存在或不属于该题库时返回 `404 QUESTION_NOT_FOUND`。
- `bankVersion` 与当前版本不一致时返回 `409 BANK_VERSION_CHANGED`；前端刷新题库列表、清除旧进度并从第 1 题开始。

### 8.4 API 边界

MVP 只提供以上三个 API，不提供：

- 身份、权限或会话 API。
- 进度、记录、错题、收藏或统计 API。
- 题库或题目的写入、导入、导出 API。
- 考试、管理、配置或审计 API。

## 9. 状态与异常处理

| 场景 | 产品行为 |
|---|---|
| 暂无题库 | 题库页显示“暂无可用题库”，不展示无效操作 |
| 题库列表加载失败 | 显示简短错误和“重试” |
| 初始题目加载失败 | 显示“重试”，不创建错误位置记录 |
| 切换题目加载失败 | 保留当前题目、选择或反馈，显示“重试”；不推进当前位置 |
| 提交失败 | 保留已选选项并允许再次提交 |
| 题库不存在或已删除 | 清除该题库本地进度，返回题库页并提示 |
| 题库版本变化 | 清除旧进度，提示更新并从第 1 题开始 |
| 本地进度损坏 | 静默忽略损坏内容并从第 1 题开始 |
| JSON 文件无效 | 服务拒绝启动并输出可定位错误 |

错误提示应说明用户下一步可以做什么，不展示堆栈、文件系统路径或其他内部实现信息。启动日志不面向最终用户，可包含题库文件定位信息。

## 10. 基础体验与安全要求

- Web 界面采用单题内容优先布局；桌面仅增加题目级右侧导航，窄屏收纳为底部抽屉。
- 所有可操作控件必须有明确的 hover、focus、disabled 和 loading 状态。
- 键盘可以完成选项选择、提交、前后切题、题号跳转、打开与关闭抽屉。
- 请求进行中不清空用户已选答案。
- 判题成功后立即渲染反馈，不使用延迟反馈的动画。
- 服务端必须校验所有答案请求，不能信任前端题型或选项状态。
- 题库 JSON 不得作为静态文件暴露，否则会直接泄露答案与解析。
- Markdown 使用白名单渲染，禁止执行 HTML 或脚本。

## 11. 验收标准

### 11.1 题库与进度

- [x] 根路由直接显示题库卡片，不存在独立首页或分类筛选。
- [x] 卡片只显示名称、简介、题数和一个主操作。
- [x] 无记录显示“开始练习”，存在位置、草稿或反馈时显示“继续练习”，不存在完成状态。
- [x] 用户中断后可在同一浏览器从正确题号继续。
- [x] 草稿和已提交反馈可跨切题、刷新与返回题库恢复，服务端不保存个人记录。
- [x] 清空记录只影响当前题库，确认后回到第 1 题。
- [x] 任意数量题目提交后均不生成完成页、分数、正确率或统计。

### 11.2 作答与反馈

- [x] 单选题与判断题只能选择一个选项并正确判题。
- [x] 多选题只有在选项集合完全匹配时才判定正确。
- [x] 空答案不能提交；非法选项由后端拒绝。
- [x] 提交成功后锁定当前题选项，不能重复作答。
- [x] 回答正确时显示正确状态、正确选项和解析。
- [x] 回答错误时同时标出错选与全部正确选项，并显示解析。
- [x] 反馈状态不只依赖颜色表达。
- [x] 提交或加载失败时保留当前上下文和选择，并可重试。
- [x] 桌面答题卡和移动抽屉均按单选、判断、多选分区并支持数字跳题。
- [x] 上一题、下一题在提交前后均可使用，首末题正确禁用且不循环。
- [x] 答题卡区分当前、草稿、已提交和未作答，但不显示对错。

### 11.3 内容加载

- [x] 合法 JSON 在重启后被载入内存并可用于刷题。
- [x] 修改 JSON 但不重启时，运行中内容不发生变化。
- [x] 任一 JSON 非法时服务拒绝启动，不发生部分载入。
- [x] 启动错误可以定位到具体文件、字段和原因。
- [x] 空题库目录允许启动，前端显示真实空状态。
- [x] 题库版本变化后，旧本地进度被清除并从第 1 题开始。
- [x] 旧版位置进度一次性重置，新版损坏记录被安全清洗且不阻断练习。

### 11.4 API

- [x] `GET /api/banks` 只返回题库摘要并按标题排序。
- [x] 取题接口不返回或泄露正确答案与解析。
- [x] 取题接口返回固定顺序的安全分区元数据，空题型不产生分区。
- [x] 判题接口返回 `isCorrect`、正确选项和必填解析。
- [x] 空答案或非法答案返回 `400`。
- [x] 不存在的题库、题目或题号返回 `404`。
- [x] 旧题库版本提交返回 `409`，前端按更新流程处理。
- [x] 除题库列表、取题和判题外不存在其他产品 API。

### 11.5 范围守卫

- [x] UI、JSON 与 API 中均不存在级别字段或选择流程。
- [x] 系统不要求账号、身份或权限。
- [x] 系统不连接数据库，也不保存服务端学习数据。
- [x] 系统不包含历史产品的考试、复习、管理或统计能力。
