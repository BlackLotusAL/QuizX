# QuizX 产品需求文档（极简 MVP）

**日期**：2026-09-02

**状态**：待评审

**产品原则**：Less is more

---

## 1. 产品定义

QuizX 是一个通用的极简刷题 Web 应用。它只解决一个问题：让用户选择适合自己的题库，逐题作答，并在每次提交后立即理解答案为什么对或错。

产品只保留以下闭环：

1. 选择题库。
2. 阅读题目并选择答案。
3. 提交答案。
4. 查看对错、正确答案和解析。
5. 进入下一题，直到完成题库。

任何不能直接缩短或改善这条链路的能力，均不进入 MVP。

### 1.1 目标用户

需要通过选择题进行自学、复习或知识检验的用户。QuizX 不限定行业、考试或知识领域，具体内容完全由题库 JSON 决定。

### 1.2 核心价值

- **选择简单**：用户根据题库名称、简介和题数直接选择，不需要理解额外分类体系。
- **作答专注**：页面一次只呈现一道题，不展示与当前作答无关的信息。
- **反馈及时**：每次提交后立即展示对错、正确答案与必填解析。

### 1.3 MVP 成功标准

- 用户从题库页只需一次点击即可进入第一题或继续上次进度。
- 每道题在提交成功后都能得到明确、完整的解释。
- 单选题、多选题和判断题均能被正确呈现与判定。
- 中断后可在同一浏览器继续，但服务端不保存任何个人数据。
- 产品运行不依赖数据库，只需要合法的题库 JSON 文件。

## 2. 产品边界

### 2.1 MVP 范围

- 题库卡片列表。
- 开始、继续、完成和重新练习题库。
- 单选题、多选题、判断题。
- 逐题作答与即时判题。
- 正确选项、错误选项和解析展示。
- 浏览器本地进度。
- 服务启动时加载并校验题库 JSON。
- 三个只服务于题库列表、取题和判题的 API。

### 2.2 明确不做

- 账号、登录、用户身份、角色或权限。
- 级别、科目、语言、标签、筛选、搜索或推荐。
- 独立首页、导航中心或营销页面；根路由直接展示题库。
- 跳题、上一题、答题卡、随机顺序或背诵模式。
- 错题本、收藏、笔记、作答历史、成绩或学习统计。
- 模拟考试、倒计时、排名、积分、徽章或证书。
- 题目管理后台、在线编辑、上传、导入或导出 API。
- 图片、附件、外链资源或富媒体题目。
- 数据库、缓存服务、消息队列或服务端进度。
- 多主题、复杂动效或独立原生移动端应用。
- 防作弊机制；该产品用于学习，不限制用户主动调用判题接口。

## 3. 信息架构

MVP 只有两个页面。

| 页面 | 路由 | 目的 |
|---|---|---|
| 题库页 | `/` | 浏览题库并开始、继续或重新练习 |
| 刷题页 | `/practice/:bankId` | 逐题作答并查看即时反馈 |

不设置侧边栏或额外一级导航。刷题页只提供返回题库页的入口。

## 4. 核心交互

### 4.1 题库页

题库按标题升序展示。每张卡片只包含：

- 题库名称。
- 一段简短介绍。
- 题目总数。
- 一个主操作按钮。

按钮文案由本地进度决定：

| 本地状态 | 按钮 | 点击结果 |
|---|---|---|
| 无进度 | 开始练习 | 从第 1 题进入 |
| 未完成 | 继续练习 | 从 `nextPosition` 对应题目进入 |
| 已完成 | 重新练习 | 清除该题库进度并从第 1 题进入 |

重新练习只覆盖本地位置状态，不涉及服务端数据，因此不需要二次确认。

### 4.2 刷题页布局

页面从上到下依次展示：

1. 返回题库页入口、题库名称和 `当前题 / 总题数`。
2. 题干。
3. 选项。
4. 主操作按钮“提交答案”。
5. 提交成功后出现的反馈区。
6. 主操作按钮“下一题”或最后一题后的“完成练习”。

页面一次只展示一道题，不提供上一题、跳题或题号导航。

### 4.3 选择与提交

- 单选题和判断题使用单选交互，只允许选择一个选项。
- 多选题使用复选交互，允许选择一个或多个选项。
- 未选择任何选项时，“提交答案”不可用。
- 点击提交后，在响应返回前禁用重复提交。
- 若请求失败，保留当前选择，恢复提交按钮并允许重试。
- 若提交成功，锁定选项；当前题不能再次作答。

判题规则：

- 单选题与判断题：所选唯一选项等于唯一正确选项时为正确。
- 多选题：忽略选项顺序，所选选项集合与正确选项集合完全相同时为正确；少选、多选或错选均为错误。

### 4.4 即时反馈

提交成功后，反馈必须直接出现在当前题下方，不跳转页面，也不增加人为等待或结果动画。

回答正确时：

- 显示“回答正确”。
- 标记正确选项。
- 显示题目解析。

回答错误时：

- 显示“回答错误”。
- 标记用户选错的选项。
- 标记所有正确选项。
- 显示题目解析。

选项状态不能只依赖颜色，还必须有文字或图标标识，确保状态可辨识。

### 4.5 下一题与完成

- 提交成功前不显示“下一题”。
- 点击“下一题”后加载下一道题；加载成功后才更新本地进度。
- 下一题加载失败时保留当前反馈，并允许重试，不提前推进进度。
- 最后一题提交成功后显示“完成练习”。
- 点击“完成练习”后，将题库标记为已完成，并显示简单完成状态。
- 完成状态只提供“返回题库”和“重新练习”，不展示分数或答题统计。

提交结果只存在于当前页面内存中。用户在查看反馈时刷新页面，将回到同一道未提交状态；系统不会保存答案或对错结果。

## 5. 本地进度

进度使用浏览器 `localStorage`，键名固定为 `quizx.progress`。

```json
{
  "javascript-basics": {
    "bankVersion": 3,
    "nextPosition": 8,
    "completed": false
  }
}
```

字段含义：

| 字段 | 说明 |
|---|---|
| `bankVersion` | 保存进度时的题库版本 |
| `nextPosition` | 下次进入时应展示的题号，从 1 开始 |
| `completed` | 是否已完成整个题库 |

约束：

- 只保存题库版本、位置和完成状态，不保存所选答案、对错、解析或成绩。
- 进行中时，`nextPosition` 范围为 `1..题目总数`。
- 完成时，`nextPosition` 为 `题目总数 + 1`，`completed` 为 `true`。
- 重新练习时重置为第 1 题且 `completed` 为 `false`。
- 本地存储缺失、不可用或内容损坏时，忽略旧值并从第 1 题开始，不阻断刷题。
- 题库列表返回的版本与本地版本不一致时，清除该题库进度，并提示“题库已更新，将从第 1 题开始”。
- 题库已被删除时，清除对应本地进度；直接访问其刷题路由时返回题库页并提示题库不存在。

## 6. 题库 JSON 规范

### 6.1 文件约定

- 路径：`data/question-banks/*.json`。
- 一个文件只定义一个题库。
- 文件编码为 UTF-8。
- 顶层字段固定为 `id`、`title`、`description`、`version`、`questions`，不记录其他版本信息。
- JSON 是题库内容的唯一真源，不同步到数据库。
- 题目按 `questions` 数组中的顺序呈现。
- 任何题目内容、答案或顺序发生变化时，内容维护者必须递增题库 `version`。
- 文件不位于 Web 静态资源目录，不能被浏览器直接下载。

### 6.2 完整示例

```json
{
  "id": "javascript-basics",
  "title": "JavaScript 基础",
  "description": "适合复习 JavaScript 核心语法与常见行为。",
  "version": 3,
  "questions": [
    {
      "id": "q001",
      "type": "single",
      "stemMd": "`const` 声明的变量具有什么特点？",
      "options": [
        { "id": "A", "text": "可以在同一作用域重复声明" },
        { "id": "B", "text": "声明后必须始终指向同一值" },
        { "id": "C", "text": "绑定不能被重新赋值" },
        { "id": "D", "text": "自动成为全局变量" }
      ],
      "correctOptionIds": ["C"],
      "explanationMd": "`const` 禁止重新赋值变量绑定，但对象内部的可变内容仍可修改。"
    }
  ]
}
```

### 6.3 字段定义

#### 题库

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| `id` | string | 是 | 全局唯一；只允许小写字母、数字和连字符 |
| `title` | string | 是 | 非空，用于题库卡片和刷题页标题 |
| `description` | string | 是 | 非空，帮助用户判断是否适合自己 |
| `version` | integer | 是 | 大于等于 1；内容或顺序变化时递增 |
| `questions` | array | 是 | 至少包含一道题 |

#### 题目

| 字段 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| `id` | string | 是 | 在当前题库内唯一 |
| `type` | enum | 是 | `single`、`multiple` 或 `judgment` |
| `stemMd` | string | 是 | 非空；支持受限 Markdown |
| `options` | array | 是 | 选项 ID 在当前题目内唯一，文本非空 |
| `correctOptionIds` | string[] | 是 | 只能引用当前题目的选项 ID |
| `explanationMd` | string | 是 | 非空；必须解释正确答案及常见错误原因 |

题型校验：

| 题型 | 选项数量 | 正确选项数量 |
|---|---:|---:|
| `single` | 2–6 | 1 |
| `multiple` | 2–6 | 至少 2 |
| `judgment` | 固定 2 | 1 |

### 6.4 Markdown 白名单

题干与解析仅支持：

- 段落与换行。
- 粗体和斜体。
- 有序与无序列表。
- 行内代码。
- fenced code block。

不渲染原始 HTML、链接、图片、脚本、内联事件或其他外部资源。选项文本始终按纯文本渲染。

## 7. 服务启动与内容加载

启动流程：

1. 扫描 `data/question-banks/*.json`。
2. 解析全部文件。
3. 按第 6 节规则校验全部题库和题目。
4. 只有全部文件都通过校验，才一次性载入内存并开始提供服务。
5. 内容在本次进程生命周期内保持只读；修改文件不会热更新，必须重启服务。

错误策略：

- 任一文件解析或校验失败，服务拒绝启动，不允许只加载部分题库。
- 错误日志必须包含文件路径、JSON 字段位置和失败原因。
- 不存在任何 JSON 文件时允许服务启动，`GET /api/banks` 返回空数组，前端展示空题库状态。
- 多个文件使用相同题库 ID 时视为校验失败。

运行时不创建数据库连接，不写入题库文件，也不提供内容修改接口。

## 8. API 契约

所有响应使用 JSON。错误统一返回：

```json
{
  "error": {
    "code": "BANK_NOT_FOUND",
    "message": "题库不存在"
  }
}
```

### 8.1 获取题库列表

`GET /api/banks`

成功响应：`200 OK`

```json
[
  {
    "id": "javascript-basics",
    "title": "JavaScript 基础",
    "description": "适合复习 JavaScript 核心语法与常见行为。",
    "version": 3,
    "questionCount": 30
  }
]
```

规则：

- 结果按 `title` 升序排列。
- 无题库时返回 `[]`，不视为服务错误。
- 不返回题目内容或答案。

### 8.2 按位置获取题目

`GET /api/banks/:bankId/questions/:position`

成功响应：`200 OK`

```json
{
  "bank": {
    "id": "javascript-basics",
    "title": "JavaScript 基础",
    "version": 3
  },
  "position": 1,
  "total": 30,
  "question": {
    "id": "q001",
    "type": "single",
    "stemMd": "`const` 声明的变量具有什么特点？",
    "options": [
      { "id": "A", "text": "可以在同一作用域重复声明" },
      { "id": "B", "text": "声明后必须始终指向同一值" },
      { "id": "C", "text": "绑定不能被重新赋值" },
      { "id": "D", "text": "自动成为全局变量" }
    ]
  }
}
```

规则：

- `position` 为从 1 开始的整数。
- 响应不得包含 `correctOptionIds`、`explanationMd` 或任何可推导正确答案的字段。
- 题库不存在时返回 `404 BANK_NOT_FOUND`。
- 题号不是正整数或超出范围时返回 `404 POSITION_NOT_FOUND`。

### 8.3 提交答案

`POST /api/banks/:bankId/questions/:questionId/answer`

请求：

```json
{
  "bankVersion": 3,
  "selectedOptionIds": ["B"]
}
```

成功响应：`200 OK`

```json
{
  "isCorrect": false,
  "correctOptionIds": ["C"],
  "explanationMd": "`const` 禁止重新赋值变量绑定，但对象内部的可变内容仍可修改。"
}
```

规则：

- 接口只判题并返回反馈，不创建会话或记录。
- `selectedOptionIds` 不能为空、不能重复，也不能包含不存在的选项。
- 单选题和判断题提交多个选项时返回 `400 INVALID_ANSWER`。
- 多选题提交一个合法选项属于有效作答，按答案集合判定，不因少选而返回 `400`。
- 题库不存在时返回 `404 BANK_NOT_FOUND`。
- 题目不存在或不属于该题库时返回 `404 QUESTION_NOT_FOUND`。
- `bankVersion` 与当前版本不一致时返回 `409 BANK_VERSION_CHANGED`；前端刷新题库列表、清除旧进度并从第 1 题开始。

### 8.4 API 边界

MVP 只提供以上三个 API，不提供：

- 身份、权限或会话 API。
- 进度、记录、错题、收藏或统计 API。
- 题库或题目的写入、导入、导出 API。
- 考试、管理、配置或审计 API。

## 9. 状态与异常处理

| 场景 | 产品行为 |
|---|---|
| 暂无题库 | 题库页显示“暂无可用题库”，不展示无效操作 |
| 题库列表加载失败 | 显示简短错误和“重试” |
| 题目加载失败 | 保留当前题号，显示“重试”；不推进本地进度 |
| 提交失败 | 保留已选选项并允许再次提交 |
| 题库不存在或已删除 | 清除该题库本地进度，返回题库页并提示 |
| 题库版本变化 | 清除旧进度，提示更新并从第 1 题开始 |
| 本地进度损坏 | 静默忽略损坏内容并从第 1 题开始 |
| JSON 文件无效 | 服务拒绝启动并输出可定位错误 |

错误提示应说明用户下一步可以做什么，不展示堆栈、文件系统路径或其他内部实现信息。启动日志不面向最终用户，可包含题库文件定位信息。

## 10. 基础体验与安全要求

- Web 界面采用单列、内容优先布局，不引入与刷题无关的视觉模块。
- 所有可操作控件必须有明确的 hover、focus、disabled 和 loading 状态。
- 键盘可以完成选项选择、提交和进入下一题。
- 请求进行中不清空用户已选答案。
- 判题成功后立即渲染反馈，不使用延迟反馈的动画。
- 服务端必须校验所有答案请求，不能信任前端题型或选项状态。
- 题库 JSON 不得作为静态文件暴露，否则会直接泄露答案与解析。
- Markdown 使用白名单渲染，禁止执行 HTML 或脚本。

## 11. 验收标准

### 11.1 题库与进度

- [ ] 根路由直接显示题库卡片，不存在独立首页或分类筛选。
- [ ] 卡片只显示名称、简介、题数和一个主操作。
- [ ] 无进度、进行中和已完成题库分别显示“开始练习”“继续练习”“重新练习”。
- [ ] 用户中断后可在同一浏览器从正确题号继续。
- [ ] 本地进度不包含答案、对错或成绩。
- [ ] 完成题库后不生成分数或统计，可返回题库或重新练习。

### 11.2 作答与反馈

- [ ] 单选题与判断题只能选择一个选项并正确判题。
- [ ] 多选题只有在选项集合完全匹配时才判定正确。
- [ ] 空答案不能提交；非法选项由后端拒绝。
- [ ] 提交成功后锁定当前题选项，不能重复作答。
- [ ] 回答正确时显示正确状态、正确选项和解析。
- [ ] 回答错误时同时标出错选与全部正确选项，并显示解析。
- [ ] 反馈状态不只依赖颜色表达。
- [ ] 提交或加载失败时保留当前上下文和选择，并可重试。

### 11.3 内容加载

- [ ] 合法 JSON 在重启后被载入内存并可用于刷题。
- [ ] 修改 JSON 但不重启时，运行中内容不发生变化。
- [ ] 任一 JSON 非法时服务拒绝启动，不发生部分载入。
- [ ] 启动错误可以定位到具体文件、字段和原因。
- [ ] 空题库目录允许启动，前端显示真实空状态。
- [ ] 题库版本变化后，旧本地进度被清除并从第 1 题开始。

### 11.4 API

- [ ] `GET /api/banks` 只返回题库摘要并按标题排序。
- [ ] 取题接口不返回或泄露正确答案与解析。
- [ ] 判题接口返回 `isCorrect`、正确选项和必填解析。
- [ ] 空答案或非法答案返回 `400`。
- [ ] 不存在的题库、题目或题号返回 `404`。
- [ ] 旧题库版本提交返回 `409`，前端按更新流程处理。
- [ ] 除题库列表、取题和判题外不存在其他产品 API。

### 11.5 范围守卫

- [ ] UI、JSON 与 API 中均不存在级别字段或选择流程。
- [ ] 系统不要求账号、身份或权限。
- [ ] 系统不连接数据库，也不保存服务端学习数据。
